# DronePilot

DronePilot is an early CAD-based drone simulation project. The repository
currently contains a STEP assembly fixture and documentation that defines the
intended workflow for CAD import, material assignment, mass-property
calculation, six-degree-of-freedom simulation, and future frontend
visualization.

- [AGENTS.md](AGENTS.md) for the coding-agent development workflow.
- [docs/README.md](docs/README.md) for the versioned project documentation.
